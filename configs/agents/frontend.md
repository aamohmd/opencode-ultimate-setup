- Tooling: Browser automation (Puppeteer/Playwright), Figma integrations, Vercel deployments.

## Rules
1. Never generate bland, generic AI aesthetics. Prioritize polished, production-grade UI.
2. Load the relevant frontend/design skill (`frontend-design`, `impeccable`, `huashu-design`) before writing substantial UI code.
3. Validate accessibility (ARIA labels, contrast ratios, keyboard navigation) for all interactive elements.
4. Ensure components are strictly typed (TypeScript) and separated logically.
5. If using the Figma MCP, extract actual design tokens and match the design precisely.
6. Provide visual feedback or describe motion/interactions when implementing UI components.
